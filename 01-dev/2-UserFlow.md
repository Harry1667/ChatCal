## 一、典型一天的使用流程

```
08:00  ☀️ 早報 Embed（金黃邊框）自動推入 Discord
         「今天共 3 件事：07:00 晨間運動 / 19:00 做晚餐 / 待辦：買牙膏」

09:00  Discord 傳：「幫我買牙膏」
         → AI 判定無時間 → 存進收件匣 → Embed 確認（灰色邊框）

10:30  Discord 傳：「明天三件事：9點晨會、下午做報告、晚上買菜」
         → AI 批次解析 → 三筆逐一 Embed（🔵工作 / 🟢學習 / 🟣生活）

10:35  Discord 傳：「把晨會改到 10 點」
         → AI 找到那筆 → 改時間 → Bot 更新確認訊息

14:00  ⏰ Discord 自動推：「60 分鐘後 — 15:00 與教授討論論文 / 帶筆電」

14:30  ⏰ Discord 自動推：「30 分鐘後 — 15:00 與教授討論論文 / 帶筆電」

16:00  Discord 傳：「論文改得差不多了」
         → AI 判定為「完成」→ 標 status=done

20:00  打開 Web → 左欄收件匣看到「買牙膏」→ 拖到本週某天完成排程

22:00  🌙 晚報 Embed（靛藍邊框）自動推入 Discord
         「明天共 2 件事 + AI 反思邀請語」

22:05  Discord 傳：「好累但論文有進度，開心」
         → AI 存成日記，挑 😮‍💨 emoji

（週日 21:00 另外收到本週回顧 Embed）
```

## 二、Discord 輸入流程

### 2.1 新增事件

```
用戶輸入
   ↓
AI 解析意圖 → 新事件
   ↓
時間衝突偵測
  ├─ 有衝突 → Embed 警告 + [確定存] [取消] 按鈕
  └─ 無衝突 → 存入 DB
                 ↓
              Embed 確認（按 category 顯示顏色）
              [✅ 完成] [⏰ 推遲30分] [✏️ 編輯時間] [🗑️ 刪除]
```

### 2.2 批次新增

```
用戶輸入：「明天三件事：9點晨會、下午做報告、晚上買菜」
   ↓
AI 解析 → 拆成 3 筆事件
   ↓
逐一時間衝突偵測 → 逐一存入 DB → 逐一 Embed 確認
```

### 2.3 修改事件

```
用戶輸入：「把 3 點的論文討論改到 4 點半」
   ↓
AI 從近期事件中比對 → 找到目標事件
   ↓
更新 start_time → Embed 確認「已更新」
```

### 2.4 重複事件修改

```
用戶輸入：「把每週三的籃球改到下午 4 點」
   ↓
Bot 詢問：「只改這次，還是之後全部改？」
  ├─ [只改這次] → 建立例外紀錄，只改當次時間
  └─ [之後全部改] → 更新主事件 + 重新展開未來所有實例
```

### 2.5 完成 / 取消

```
用戶輸入：「論文寫完了」 / 「今晚火鍋取消」
   ↓
AI 比對近期事件 → 找到目標
  ├─ 完成 → status = done → Embed 確認「✅ 已完成」
  └─ 取消 → 刪除事件 → Embed 確認「🗑️ 已刪除」
```

### 2.6 日記 / 反思

```
用戶輸入：「今天好累，但功能跑起來了，很爽」
   ↓
AI 判定為日記意圖
   ↓
AI 整理文字 + 自動挑 emoji（如 😮‍💨）
   ↓
存入 reflections（今天的日期）
   ↓
Bot 回覆：「📓 已記錄今天的心情 😮‍💨」
```

## 三、Discord Slash 指令流程

| 指令 | 觸發 | 回覆內容 |
|------|------|---------|
| `/today` | 任意時間 | 今日所有事件 Embed，每條帶 ✅ 完成按鈕 |
| `/list` | 任意時間 | 未來 7 天行程列表 |
| `/morning` | 任意時間 | 立刻發早報 Embed（等同 08:00 自動推播） |
| `/evening` | 任意時間 | 立刻發晚報 Embed（明日預告 + 反思邀請） |
| `/week` | 任意時間 | 立刻發本週回顧 Embed |
| `/month` | 任意時間 | 本月完成 / 錯過 / 待續統計 + 各 category 完成率 |
| `/inbox` | 任意時間 | 列出所有「未定時間」待辦 |
| `/reflect` | 任意時間 | 不帶參數 = 查今日日記；帶參數 = 寫入日記 |
| `/search q:關鍵字` | 任意時間 | 全文搜尋結果（標題 / 描述 / 備註） |
| `/done id:12` | 任意時間 | 把 #12 標成完成 |

## 四、自動推播流程

### 4.1 早報（08:00）

```
cron 觸發
   ↓
查詢今日所有事件（含重複展開）
   ↓
分組：有時間（時間表）/ 無時間（待辦）
   ↓
組成 Embed（金黃色邊框）→ 推入 Discord 頻道
```

### 4.2 晚報（22:00）

```
cron 觸發
   ↓
查詢明日事件
   ↓
AI 根據今日事件生成個性化反思邀請語（每次不同）
   ↓
組成 Embed（靛藍色邊框）→ 推入 Discord 頻道
```

### 4.3 事前提醒（事件前 60 / 30 分鐘）

```
每分鐘 cron 掃描
   ↓
找出 60 / 30 分鐘內開始 + reminded_60/30 = 0 的事件
   ↓
發送 Embed（含事件描述）→ 設 reminded_60/30 = 1
```

### 4.4 週回顧（週日 21:00）

```
cron 觸發
   ↓
統計本週：完成 X / 錯過 Y / 待續 Z
   ↓
AI 生成手帳式文字總結
   ↓
組成 Embed → 推入 Discord 頻道
```

## 五、Web 介面使用流程

### 5.1 日常整理（收件匣 → 排程）

```
左欄「收件匣」出現未定時間的事件卡片
   ↓
用戶拖曳卡片到右頁時間軸的目標日
   ↓
自動設定日期（時刻預設 9:00）→ 彈出編輯 modal 確認
   ↓
存入 DB → 收件匣清空該筆
```

### 5.2 Category Tab 過濾

```
右頁頂部：[全部] [🔵工作] [🟢學習] [🟣生活]
   ↓
點擊 Tab → 時間軸即時只顯示對應 category 的事件
   ↓
月曆色點也同步過濾
```

### 5.3 編輯事件

```
點擊時間軸任一事件
   ↓
彈出編輯 modal：標題 / 時間 / 重複 / 描述 / 備註 / 狀態 / Category
   ↓
存檔 → API PATCH → 畫面即時更新
   ↓
（重複事件）詢問：只改這次 / 之後全部改
```

### 5.4 寫日記

```
右頁下方日記卡（灰白貼紙感）
   ↓
點選心情 emoji（😊😌🥲😤😴🎉💪🌧️）
   ↓
在文字區輸入今日反思
   ↓
按存 → API PUT /reflections/:date → 月曆當日顯示心情 emoji
```

### 5.5 快速輸入（Web 底部列）

```
輸入框打字（同 Discord 自然語言）
   ↓
POST /api/events → 同一套 AI 解析
   ↓
畫面即時刷新
```

## 六、使用情境模擬

### 情境 A：課堂上接收資訊（行動優先）

```
上午 10:00（校園移動中）
   ↓
教授公佈報告死線 → 對 Discord 傳「6月15日期末專題報告」
   ↓
AI 自動建檔：標題「期末專題報告」/ 時間 06-15 09:00 / category=study
   ↓
Embed 確認（🟢 綠色）推回 Discord
```

### 情境 B：靈感閃現（收件匣暫存）

```
下午 2:00（上課中）
   ↓
腦中閃過創業點子 → Discord 傳「幫早餐店算帳的系統」
   ↓
AI 判定無時間 → 進收件匣
   ↓
晚上回電腦 → Web 左欄拖到週六 / 貼上 category=work
```

### 情境 C：衝刺工作（Tab 過濾專注）

```
晚上 8:00 打開 Web
   ↓
點擊「🔵 工作」Tab
   ↓
學校報告、聚餐等全數隱藏 → 只剩客戶開會、接案進度
   ↓
進入深度工作狀態
```
